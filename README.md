# 📊 Mini Pipeline d'Analyse Data (Python & SQL)

## 📌 Présentation du Projet
Ce projet met en place un pipeline d'analyse de données automatisé. Il simule l'ingestion de données de ventes, effectue des transformations via Python (Pandas) et exécute des requêtes SQL modularisées sur une base SQLite en mémoire pour générer des indicateurs clés.

## 🛠️ Technologies & Outils
* **Langage :** Python 3.x
* **Analyse de données :** Pandas
* **Base de données :** SQLite3
* **Requêtes SQL :** SQL (fichiers `.sql` modularisés)
* **IDE & Versioning :** VS Code, Git, GitHub

## 📁 Structure du Projet
```text
├── analyse.sql    # Requetes SQL d'analyse (agrégations, filtres)
